# Himesh Vaishnav — B.Tech Journey Portfolio

A responsive single-page portfolio built with Next.js App Router, TypeScript, Tailwind CSS, and Lucide React.

## Run locally

1. Install Node.js (LTS recommended).
2. Extract the ZIP and open this folder in VS Code.
3. In the terminal, run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Personalize before publishing

- Replace the `HV / YOUR PHOTO HERE` placeholder in `app/page.tsx` with your real profile image.
- Replace social links and labels in the `socials` array.
- Update the email fallback `YOUR_EMAIL@example.com` in `app/page.tsx`.
- Add your real Univ SVH certificate at `public/images/univ-svh-certificate.png` and replace the certificate placeholder.
- Add project demo and GitHub URLs in the `projects` array.
- Add your resume at `public/resume/himesh-resume.pdf` when ready.
- Replace creative gallery placeholders with real reel thumbnails and links.
- Review all skill names so they accurately reflect your current level.

## Notes

- Power BI and BI dashboard content are intentionally excluded.
- Only one certificate is included: Univ SVH — Industrial Training.
- Future journey years are presented as planned milestones, not completed achievements.
- Project and social links are placeholders until you add real URLs.
